GYM OPERATORS SHOW OFFERS

Open index.html to browse all 31 offers alphabetically.
Each business has a separate HTML page with the exact offer from the first worksheet of the supplied spreadsheet. The second worksheet contains prize draw questions and is outside this offers-only build.

Upload all files together, retaining their relative paths. No build tools or external assets are required. Layouts adapt for mobile.

FORM CONNECTION REQUIRED
Forms are not connected to a submission service. They do not save or send data until configured. Set window.OFFERS_FORM_ENDPOINT in config.js to an HTTPS endpoint accepting URL-encoded POST fields: name, business, email, phone, offerBusiness, offer. The endpoint must validate and store submissions, route them to the appropriate business, allow CORS for the hosted origin and return JSON {"success":true} only after successful processing. Add the appropriate privacy policy link before launch. No existing prize draw endpoint has been reused.
